# Santeq + Vlonderschroeven - klantpreview

Statische ontwerpweergaven voor feedback van de opdrachtgever.

- [Santeq bekijken](https://sander0345.github.io/santeq-vlonderschroeven-preview/santeq/)
- [Vlonderschroeven bekijken](https://sander0345.github.io/santeq-vlonderschroeven-preview/vlonderschroeven/)

## Inhoud

`santeq/` bevat de volledige statische bedrijfswebsite. `vlonderschroeven/` bevat de statische winkelpreview met productpagina's, zoekfunctie, winkelmand en het ontwerp van de afrekenpagina.

De shop gebruikt duidelijk gemarkeerde voorbeeldprijzen en voorraad. Betalingen staan uit; de demo verstuurt geen adresgegevens en maakt geen echte orders aan. De echte backoffice, database en Mollie-sleutels maken geen deel uit van deze openbare preview. Het Santeq-contactformulier opent uitsluitend een e-mailconcept in het eigen mailprogramma.

## Publicatie

GitHub Pages publiceert `main`, map `/ (root)`. `.nojekyll` houdt de HTML-bestanden ongewijzigd. Alle sitepaden werken onder de repository-submap.

De oorspronkelijke websites en domeininstellingen worden hiermee niet veranderd. Zoekmachine-indexering is uitgeschakeld via noindex en robots.txt; dit is geen toegangsbeveiliging. Iedereen met de link kan de ontwerpen bekijken.

## Lokaal bekijken

Open `index.html`, of start in deze map `python3 -m http.server 8080` en bezoek `http://localhost:8080`.

## Eigendom

Geen opensourcelicentie verleend. Bestaande rechten op logo's, teksten, code en afbeeldingen blijven bij hun rechthebbenden.
